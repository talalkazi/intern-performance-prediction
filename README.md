# 📈 Intern Performance Prediction Model

A machine learning web application designed to predict intern and employee performance scores based on workplace metrics, feedback, and professional history. Built using Python, Scikit-Learn, and Streamlit.

## 🚀 Features
* **Interactive Web Interface**: Built with Streamlit for real-time parameter tuning and instant predictions.
* **Machine Learning Pipeline**: Utilizes a `RandomForestRegressor` trained on workplace features to evaluate risk levels (Excelling vs. At-Risk).
* **Feature Importance Insights**: Visualizes key metrics driving the model's decisions.

---

## 🛠️ Tech Stack
* **Language**: Python 3.x
* **Machine Learning**: Scikit-Learn, Pandas, NumPy
* **Frontend / UI**: Streamlit
