# Intern Performance Prediction Model

A machine learning project that predicts intern performance based on workplace, experience, workload, training, satisfaction, and other relevant factors.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Widgets

## Project Features

- Data preprocessing
- Exploratory Data Analysis
- Feature engineering
- Machine learning model training
- Model comparison
- Model evaluation
- Interactive performance prediction

## Dataset

The dataset contains approximately 100,000 records and multiple features related to employee/intern performance.

## How to Run

Open the notebook:

`InternPerformancePredictionModel.ipynb`

in Google Colab and run the cells sequentially.
